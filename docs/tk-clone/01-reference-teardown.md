# TKPostAI 拆解笔记(自建参考)

> 目的:自建一个面向 TikTok 渠道的短剧分销/发布平台,以 TKPostAI 为功能参考。
> 原则:只对标功能,不使用对方的名称、文案、素材、接口实现。

## 一、TKPostAI 是什么(我们实际接触到的)

面向短剧出海的分销/推广工具:创作者(或小 B 工作室)登录后选剧、拿推广链接、
进剪辑、发布到 TikTok 获客变现。它自己不持有剧,剧由平台方(我们这种)提供。

### 产品模块(按我们观察到的面)

1. **账号体系**
   - username/password 注册(用户名 ≥ 8 字符)
   - 登录发 Bearer token,2 小时有效
   - 我们作为集成方给用户自动开号(fox%07dt%d 规则),说明它支持纯 API 开号
2. **推广链接(drama links)**
   - 集成方拿 token 调接口,传 dramaid/title,得到一条链接
   - 链接直达已登录的创作工作台(免手动登录)
   - 链接有使用次数概念(remaining_uses)
   - 有防重放(同链接短时间重复访问会 REPLAY_DETECTED,15 分钟内可复用缓存)
3. **创作者工作台**
   - 可推广剧目列表
   - 从工作台进"AI 视频剪辑"——跳转到 DramaCut(带 tenantId/externalUserId 凭证)
4. **对外集成 API(我们有完整文档)**
   - POST /api/integrations/auth/register {username, password}
   - POST /api/integrations/auth/login → bearer token(2h)
   - POST /api/integrations/drama/links {appid, token, dramaid, title}
   - 旧版 HMAC 签名接口已废弃 → 说明他们接口也在迭代,核心就是"开号+发链"
5. **商业模式(推断)**
   - 向平台方/分销商收订阅或按量费
   - 剪辑能力是外挂增值(DramaCut),不是自研

### 对我们最有用的启示

- 它把"平台方"和"创作者"分成两类账号,中间用**链接**衔接——这个结构值得照抄
- token 2h + 链接直达,是低摩擦设计,对转化很重要
- 剪辑可以外接,不必自研

## 三、MVP 建议(先做最小闭环)

第一版只做一条链路:**注册 → 选剧 → 连 TikTok → 排队发布 → 看结果**

1. 分销账号注册/登录(直接复用现有用户体系+JWT)
2. 工作台页面:剧目列表 → 选剧 → 生成发布任务
3. TikTok 连接页(唤醒现有 OAuth 代码)
4. 发布队列跑通 + 发布列表展示状态
5. 数据:先只记"发布成功/失败 + TikTok 播放数(接口有)"

第一版不做:剪辑入口(以后外接)、订阅计费(内测免费)、多级分销、数据大屏。

## 四、法律与安全注意

1. 只对标功能,不用对方的品牌、截图、文案
2. TikTok 发布必须走官方 Content Posting API(我们已在做),不要碰非官方接口
3. 剪辑如外接第三方,凭证一律服务端存储,不进前端

## 五、实地考察补充(2026-10-29 登录 TKPostAI 工作台实测,账号 fox0000536t1)

### 信息架构
发布工作台 / 视频素材 / 账号管理 / 任务中心 / 个人中心 / AI 视频剪辑。
中英双语切换。团队体系:普通团员 · LEADUP(有团长/团员层级)。

### 发布任务(三步向导)——核心差异所在
- **平台**:TikTok + **Facebook** 双平台
- **规模**:单任务最多 500 视频 × 500 账号;"批量选择前 N 个账号"
- **提交时间**:立即 / 定时
- **发布模式**:
  - 草稿上传 = 送到 TikTok App 内人工编辑后发布
  - 直接发布 = 按设置直接提交
- **视频分配规则(矩阵引擎)**:
  1. 每个账号一个视频(一对一,账号并发)
  2. 每个账号发布全部视频
  3. 随机均匀分配(控制单视频重复上限)
  4. 视频不足时循环使用
- **描述来源**:素材自带描述 / 统一填写
- **发布设置**:可见范围、允许评论、允许合拍、允许拼接、品牌内容声明、AI 生成标记
  → 逐项对应 TikTok Content Posting API 参数(privacy_level / disable_comment / disable_duet / disable_stitch / branded_content / AIGC)

### 账号接入(关键)
- OAuth 官方授权(状态机:已连接 / 已断开 / **需重新授权** = token 到期续授权)
- **7 天有效的"账号授权链接"**:生成后发给号手/团员,对方点链接替你完成授权,
  账号自动进你的矩阵 —— 团队裂变的核心机关
- AI 剪辑是独立激活的功能位(未激活不可用)

### 任务状态机
进行中 / 已送达 / 需处理 / 失败 / **待核对**(草稿送达后需人工核对)

### 对我们克隆的直接结论
1. 发布引擎(上传+发布+参数)我们的 TikTok worker 已有 80%,缺的是**任务分配器**和**批量 UI**
2. 授权链接机制必须抄 —— 一人授权 N 号的裂变入口
3. 草稿模式是合规安全垫:API 未过审期间也能全流程作业
4. Facebook 平台后补,不影响 MVP
5. 界面上未见充值入口(普通团员侧),计费应在团长/平台侧 —— 我们第一版免费内测即可对齐
